# UI/UX brief

## Product direction

Calm, information-dense enterprise SaaS UI with clear status, predictable
navigation, and no decorative controls that lack behavior.

## Layout

- Responsive left navigation for Dashboard, Employees, Attendance, Leave, and
  Settings.
- Top bar with organization context, search, notifications, and user menu.
- Main content uses a page title, concise actions, filters, and a responsive
  content region.
- Tables become cards or horizontally scrollable regions on narrow screens.

## Design system

- Neutral surfaces with one accessible brand accent.
- Semantic status colors for pending, approved, rejected, active, and inactive.
- Consistent spacing, focus rings, form labels, validation messages, and
  destructive-action confirmation.
- Loading skeletons, actionable empty states, and explicit error recovery.
- Keyboard navigation and semantic landmarks are required for every workflow.

## Core screens

1. Role-aware dashboard
2. Employee list and employee form
3. Employee profile and employment history
4. Attendance history and correction request
5. Leave balance, request form, and approval queue
6. Settings for organization, departments, roles, and audit history
